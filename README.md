# TradingLab — เว็บวิจัยระบบเทรดและแจ้งสัญญาณ

เป็นเว็บสำหรับดูกราฟ ทำ Backtest / Walk-Forward / Monte Carlo คำนวณ Lot และ R:R และรับสัญญาณเทรดพร้อม Lot / SL / TP ไปเปิดใน MetaTrader 5
เซิร์ฟเวอร์รันบนคอมของคุณ ส่วนมือถือและ iPad ใช้ผ่านเบราว์เซอร์ได้

## เริ่มใช้งาน
1. ดับเบิลคลิก `start_server.bat` (ต้องเปิดค้างไว้)
2. เปิด `http://localhost:8800` บนคอม หรือ `http://<IP ของคอม>:8800` บนมือถือที่ต่อ WiFi เดียวกัน
3. (แนะนำ) เปิด MT5 ทิ้งไว้ ระบบจะใช้ราคาและสเปกของโบรกเกอร์คุณโดยตรง จากนั้นไปหน้า **ระบบเทรด** แล้วกด **รันวิจัยใหม่**
4. หน้า **ตั้งค่า**: ใส่ทุน และชื่อสัญลักษณ์ใน MT5 (เช่น Exness อาจเป็น `XAUUSDm` และ NAS100 เป็น `USTEC`)
5. ติดตั้งแอป **ntfy** บนมือถือ → Subscribe topic ที่แสดงในหน้าตั้งค่า → กด **ส่งทดสอบ**

## หน้าเว็บ
| หน้า | ใช้ทำอะไร |
|---|---|
| สัญญาณ | สัญญาณที่เข้าได้ตอนนี้: LONG/SHORT, Lot, SL, TP, R:R, ปุ่ม **ปรับตามราคา MT5**, บันทึกว่าเปิดหรือข้าม, ผล forward test |
| ระบบเทรด | ผลวิจัยของแต่ละสินทรัพย์ (ACTIVE / WATCH / OFF), เกณฑ์ที่ผ่านหรือไม่ผ่าน, folds, Monte Carlo, บันทึกจาก AI |
| กราฟ | แท่งเทียน H1/H4/D1 พร้อมเส้น indicator และจุดเข้า/ออกของระบบ |
| Strategy Lab | ทดลองกลยุทธ์และพารามิเตอร์เอง: Backtest → Walk-Forward → Monte Carlo |
| เครื่องคำนวณ | Position size, R:R, SL/TP ทั้งแบบราคาและแบบ pips |

### ตั้งค่าครั้งแรก (ทำครั้งเดียว)
1. สร้าง repository ใหม่บน GitHub (Public เพื่อใช้ Pages และ Actions ฟรี) แล้ว push โฟลเดอร์นี้ขึ้นไป
2. **Settings → Pages → Source: GitHub Actions**
3. **Settings → Secrets and variables → Actions**
   - Secret `NTFY_TOPIC` = ชื่อ topic ของ ntfy (ตั้งให้เดายาก)
   - Variable `ACCOUNT_BALANCE` = ทุน (ใช้คำนวณ lot ในข้อความแจ้งเตือน)
4. **Actions → TradingLab → Run workflow → research** เพื่อรันครั้งแรก
5. บนมือถือ: เปิดเว็บ → ตั้งค่า → ใส่ทุนและชื่อสัญลักษณ์ MT5 → เพิ่มไปยังหน้าจอโฮม
